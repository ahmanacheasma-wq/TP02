
# GSI Academic Project — TP02

Projet du Workshop MTI, Master 1 GSI, année universitaire 2026-2027.

## Objectif

Modéliser la maquette académique avec la programmation orientée objet en Python.

## Classes

- `AcademicElement` : classe abstraite commune.
- `Module` : notes, moyenne, crédits et volume horaire.
- `Unit` : regroupe plusieurs modules.
- `Semester` : regroupe plusieurs unités.

## Execution

Lancer le programme :

```bash
python main.py
```

Executer les tests :

```bash
python -m pytest -v
```

## Concepts utilises

- Classes et objets
- Encapsulation
- Héritage
- Abstraction
- Composition
- Redéfinition des méthodes
- Tests automatisés
